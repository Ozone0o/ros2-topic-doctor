# Security policy

Please do not disclose a suspected vulnerability in a public issue. Use a
private GitHub Security Advisory for this repository, or contact the project
maintainers privately through the repository owner.

Include the affected version, a minimal reproduction, the expected impact, and
any safe mitigation. Remove credentials, robot addresses, logs containing
personal data, and other sensitive deployment details before sending a report.

Roscope is an observability tool. Treat its ROS graph and captured diagnostics
as potentially sensitive operational data, and review any command copied from
its reports before executing it.
